Selected Work

Colourways

Unreal Engine

A small puzzle game developed in Unreal Engine, using real time texture painting combined with global shaders to allow you to uncover the world around you through paint and trial and error.

Painting System

I created a system that tracks the location of impact of the paint particles in game and alters the texture of the hit object to add a paint splatter.

Shaders

I implemented a cel shader which removes all shading on surfaces which are unpainted, then adds shading to painted areas in order to reveal the map.

Technical Art

Unity

I completed a unit on technical art where I picked up many different skills such as procedural landscape materials, material parameter collections, character animations, dynamic shader materials and niagara particle systems.

Parallax Occlusion Mapping

Built a Parallax Occlusion Mapping shader utilizing heightmap raymarching for real-time surface depth, self-shadowing, and occlusion on flat geometry, with exposed parameters to balance visual fidelity and performance.

Material Parameter Collections

I learnt how to use a Material parameter collection which allowed me to adjust many aspects of the world at once, which I used to create a global weather system, adjusting rain particles, cloud density, puddle accumulation and more.

Asteroid Survival

Raylib

I made a small Raylib game which I compiled with emscription to web, the game consists of a simple game loop of dodging incoming enemies and causing them to collide with one another.

Low-Level Graphics

I utilised primitive shapes and solid colour textures meaning the game would need no additional assets. Then used score particle effects and screen shake to enhance the gameplay feel.

Webhook

I created a leaderboard using a serverless database on cloudflare which the game calls to read current scores from, and writes the player's score to on completion of each round.
